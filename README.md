# Paradox Lab Portfolio

**AI-Native Engineering & Vibe Coding**

Personal portfolio website showcasing Python automation, crypto bots, and backend engineering projects.

## 🚀 Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Fonts**: Inter, JetBrains Mono (self-hosted)
- **Deployment**: GitHub Pages
- **SEO**: Sitemap, robots.txt, Open Graph tags

## 📁 Project Structure

```
/
├── index.html          # Main portfolio page
├── sitemap.xml         # SEO sitemap
├── robots.txt          # Crawler instructions
├── og-image.png        # Social media preview image
└── fonts/              # Self-hosted fonts (Inter, JetBrains Mono)
```
